## Ebbtideのリトルバード・ヘリコプターの使い方：役割と戦術

RTSゲームで軽ヘリコプターが失敗する理由は一つだ — 指揮官がそれをガンシップとして使うからだ。リトルバードはまずユーティリティ・プラットフォームであり、攻撃プラットフォームは二の次だ。その階層に沿って命令を組み立てよう。

| ミッション役割 | 適性 | 運用方法 |
|---|---|---|
| 屋上への分隊投入 | 優秀 | 素早く降下し、さらに素早く離脱。パッドで待機しない |
| 民間人／生存者の回収 | 優秀 | 機体到着前に着陸地点を事前に制圧 |
| 偵察とマップ視界 | 優秀 | 外周を飛行し、建物のラインに沿い、開けた空を避ける |
| 対歩兵掃射 | 良好 | 短いパスのみ。群れが集まる前に接触を断つ |
| 対車両任務 | 状況次第 | 孤立した目標へのロケット攻撃。護衛付きの縦隊には決して行わない |
| 前線での殴り合い | 不良 | 地上火力と衝突リスクで無駄なアセットになる |
| 貨物輸送や重量物吊り上げ | 役割外 | 大量物流にはより大型の機体を使う |

搭載構成の判断も同じ論理に従うべきだ。非武装またはドアガンナー付きの輸送構成は、ロケット満載の構成よりもほぼ常に価値が高い。なぜならヘリコプターの本当の製品は*ポジショニング*であり、ダメージではないからだ。

- **必要になる前にルートを飛ぶ。** 空が静かなうちに、投入と離脱の回廊を早めにたどっておく。
- **前線作戦基地から展開する。** 短いホップは燃料あたりのソーティ数を増やし、露出を減らす。
- **砲撃のタイミングと組み合わせる。** 弾幕が止んだ瞬間にリトルバードを送り込む。弾幕の最中ではない。
- **予備の機体を確保する。** 消耗は確実だ。補充をビルドオーダーに組み込んでおく。
- **高度を盾にする。** 屋上レベルの飛行は、ほとんどの地上脅威の視線より下に留まれる。

## 基地建設、避難、そして機体を生かし続けること

Ebbtideが基地建設と前線作戦基地を重視している以上、航空戦力はその背後のインフラ次第だ。近くにパッド、燃料、修理能力がなければ、ヘリコプターは片道旅行になる。航空をまずサプライチェーンの問題として扱おう。

| 脅威 | Ebbtideのリトルバード・ヘリコプターにとって痛い理由 | 対処法 |
|---|---|---|
| 屋上に群がるアンデッド | 接触ダメージと着陸地点の封鎖 | 投入前に歩兵でパッドを偵察する |
| 継続的な小火器射撃 | 最小限の装甲ではシステム損傷が急速に進む | 高速で予測不能な進入角度を飛ぶ |
| 視界不良や煙に覆われたLZ | 進入中止は燃料と時間を浪費する | すべての任務前に第二のパッドを確保する |
| 燃料と滞空時間の制限 | 任務途中での早期撤退を余儀なくされる | 前方展開し、ソーティを短く保つ |
| 建物への衝突 | 貴重なアセットの即時喪失 | スカイラインを覚える。低高度で盲目飛行はしない |
| 砲撃タイミングの衝突 | 自軍回廊へのフレンドリーファイア | 発進前に火力任務を調整する |

飛行前のルーティンは、どんな単一の戦術よりも役に立つ。

1. 着陸地点がクリアで燃料範囲内にあることを確認する。
2. 搭乗・降車の間、パッドを保持する地上護衛を割り当てる。
3. 着地する*前に*離脱ルートを設定する。
4. 修理と補給をキューに入れ、帰還時にミッション対応可能な状態にする。
5. 損失を記録し生産を調整する — 任務ごとに1機失っているなら、問題はユニットではなく進入角度だ。
