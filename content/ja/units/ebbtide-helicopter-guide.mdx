## ヘリコプターの主要な役割とその飛ばし方

### まず偵察、射撃は二の次

あらゆるサバイバルRTSにおける航空戦力の最も過小評価された使い方は情報だ。早い段階でヘリコプターを上げ、接近経路を把握し、大群がどこに集まっているかを特定し、その裏通りが近道なのか死の罠なのかを確認する。偵察の一度の飛行で歩兵分隊一つをまるごと救える。脅威が大規模かつ方向性を持つEbbtideでは、その情報優位は試合全体を通じて複利的に効いてくる。

### 味方を殺さない近接航空支援

空対地射撃が最も輝くのは、大群の*前縁*を打つときであり、防御線の真ん中を打つときではない。歩兵をバリケードから後退させ、大群をバリケードに群がらせてから、攻撃を味方部隊と平行ではなく垂直に走らせる。ゲームが攻撃ランを多少なりとも制御できるなら、常に目標の背後に空の通りが来るベクトルを選ぶこと。

### 避難と空輸の規律

避難ミッションはEbbtideで最も興味深い約束の一つであり、同時に新規プレイヤーがヘリコプターを失う場面でもある。ルールは単純だ。着陸地点はコミットする前に安全にするのであり、後ではない。火砲や地上射撃でLZを制圧するか薄くし、積み込みに必要な時間だけ着地し、離陸する。LZが危険なら中止せよ — 失ったヘリコプターは避難の遅れ以上のコストになる。

| 段階 | すべきこと | 避けるべきこと |
|---|---|---|
| 接近 | 高く飛び、高度からLZを偵察する | 最初の進入で真っすぐ飛び込む |
| 着地 | 降下前に区域が安全であることを確認する | 安全が確保されていない屋上の上でホバリングする |
| 積み込み | 機体を退出経路に向けておく | 脅威軸に背を向ける |
| 離脱 | 即座に上昇し、素早く高度を稼ぐ | 通りの峡谷を低空でかすめて飛ぶ |

## 位置取りと脅威管理

高度があなたの装甲だ。ゾンビは撃てないが、群がることはできる。混雑した通りの上で低くホバリングせざるを得ないヘリコプターは、エンジンに一度でも異常が起きれば残骸になる。高度は、ミッションが要求するときだけ使う資源として扱え — 着陸、積み込み、あるいは精密打撃の実施などだ。

騒音も計画すべきもう一つの要素だ。サバイバルゲームでは、航空機はしばしば注意を引く。Ebbtideの大群が音に反応するなら、静かな区域の上をヘリコプターで飛ぶことは、そこを騒がしくする最良の方法であり、包囲された拠点から圧力を引き剥がそうとするときには有用だ — そして避難車列をこっそり通そうとするときには悲惨な結果になる。

| 脅威 | 実践的な対処 |
|---|---|
| 飛行経路の下に集まる大群 | 迂回し、真上を飛ばない |
| 対空または遠距離の特殊敵 | まず偵察し、最大射程から攻撃する |
| 味方戦線への誤射 | 歩兵に対して垂直に攻撃する |
| 燃料、弾薬、クールダウンの制限 | 一機を酷使せず、機体をローテーションする |
| 最悪のタイミングで航空援護を失う | 予備機体を一機確保しておく |

## ヘリコプターと地上部隊の組み合わせ

真空状態の航空戦力は無駄だ。最も重要なEbbtideヘリコプターガイドは統合戦力のそれである。ヘリコプターが突破口を作り、地上部隊がそれを活用する。装甲は歩兵をずたずたにする圧力を受け止め、歩兵はヘリコプターが占領できない地面を保持し、火砲は航空機がこれから叩こうとしている集団そのものを柔らかくする。

| 地上資産 | ヘリコプターのパートナー | 組み合わせが機能する理由 |
|---|---|---|
| 歩兵分隊 | 偵察ヘリコプター | 航空が大群を発見し、歩兵が待ち伏せを設定する |
| 装甲車両 | 近接航空支援 | 装甲が大群を釘付けにし、航空が側面を打つ |
| 前線基地 | 輸送ヘリコプター | 航空が基地への補給と増援を維持する |
| 火砲陣地 | 監視ヘリコプター | 航空が目標を発見し、火砲がダメージを与える |
| 避難車列 | 空輸ヘリコプター | 航空が経路を切り開き、取り残された者を収容する |

## ヘリコプターを破壊に導く5つの過ち

- **航空を最初に投入する。** 地上部隊を送って接触を生じさせ、その接触が明らかにしたものをヘリコプターで活用せよ。
- **ダメージを眺めるためにホバリングする。** 射撃し、効果を確認し、移動する。静止した航空機は標的だ。
- **予備を無視する。** 唯一のヘリコプターが空中にいるなら、航空戦力はなく、賭けをしているだけだ。
- **安価な目標に航空を使う。** ライフル分隊で対処できる少数のはぐれ者にヘリコプターを費やすな。
- **目標を忘れる。** ヘリコプターは避難、防衛、押し込みを可能にするために存在する — キルを稼ぐためではない。
