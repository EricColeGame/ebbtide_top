## Ebbtideとは何か（そして何ではないか）

Ebbtideは、ゾンビファンなら誰もが議論してきた疑問を投げかける。群れと自分で戦うのか、それとも上空から戦闘を指揮するのか。オンラインに出回っているゲームプレイ映像を見る限り、答えは「両方」だ。そして、いつ切り替えるかを知ることが、このゲームにおける最大のスキルギャップである。本Ebbtideゲームプレイガイドでは、実際に確認できたシステムを分解して解説する。分隊指揮、拠点建設、装甲車両、砲撃支援、屋上防衛だ。初日にパニックに陥るより、初日から役に立ちたいなら、このEbbtideゲームプレイガイドを開始時のブリーフィングとして扱ってほしい。

Ebbtideは、崩壊しつつあるロサンゼルスを舞台にした開発中のストラテジー・サバイバル・ハイブリッドだ。軍隊を指揮するか、地上で戦うかのどちらかを選ばせるのではなく、両方を与えてくれる。街中で一人の生存者としてプレイし、その後、指揮ビューに戻って分隊、装甲車両、ヘリコプターを巨大なゾンビの群れに対して指揮できる。コミュニティの映像では、屋上防衛、民間人の避難、要請による砲撃も確認できる。

この組み合わせこそ、細部が重要な理由だ。RTSレイヤーと直接操作の戦闘を融合したゲームは、2つのモードをどれだけスムーズに行き来できるかで生死が決まる。初期映像を見る限り、その切り替えこそが体験の中心にあるようだ。ただし注意点がある。Ebbtideはまだ開発中であり、ビジュアル、バランス、さらにはプレビューで示された機能でさえ、ローンチ前に変わる可能性がある。あらゆるEbbtideゲームプレイガイド、これを含めて、ルールブックではなくスナップショットとして扱うべきだ。

| システム | 映像で確認できること | あなたにとっての意味 |
|---|---|---|
| 生存者の直接操作 | 市街地で徒歩戦闘 | あなたは単なるカーソルではなく、マップ上のユニットだ |

| 航空支援 | 戦闘に参加するヘリコプター | ダメージだけでなく機動性と回収 |
| 砲撃 | 要請式の攻撃 | 密集した脅威のために温存するのが最善 |
| 民間人避難 | 護衛型の目標 | 最悪のタイミングで注意を分散させる |

## コアループ：Ebbtideの1セッションの流れ

プレイヤー体験から見ると、セッションは単一の脚本化されたキャンペーン進行ではなく、繰り返しのリズムで進むようだ。手元を安定させ、増強し、支配範囲を広げ、その反動を生き延びる。プレッシャーの源は、建設と戦闘が同じ注意力を奪い合うことにある。メニューに費やす1秒は、群れがあなたの防衛線へ歩み寄る1秒でもある。

| フェーズ | 典型的な焦点 | 優先アクション |
|---|---|---|
| 安定化 | 開始位置を確保する | 防御範囲を設定し、チョークポイントを特定する |
| 建設 | 生産と防衛を確立する | 拡張余地を残して前線基地を配置する |
| 拡張 | 争奪ブロックへ押し込む | 歩兵で車両を援護し、退路を確保する |
| 防衛 | 大規模な群れの押し込みを耐える | 砲撃を事前配置し、屋上を保持し、負傷した分隊を交代させる |
| 回復 | 損失を建て直す | 再進軍の前に破壊された資産を補充する |

多くのプレイヤーが負けるのは「防衛」フェーズだ。なぜなら、それはまだ拡張の途中に訪れるからだ。対策は地味だが効果的だ。捨てる余裕のない拡張は始めないこと。攻勢が崩れたとき、準備された防衛線へ下がれば失うのは土地で済むが、何もない場所へ下がればランそのものを失う。

## 指揮モード vs. 直接操作

本Ebbtideゲームプレイガイドの残りは、あなたがほとんどの時間を、大きく異なる2つの思考様式の間で切り替えることを前提としている。指揮モードは情報と兵站のためのもの。直接操作は実行のためのもの。どちらが「優れている」わけではない。間違いは、心地よいからといって一方に留まり続けることだ。

| 側面 | 指揮モード | 直接操作 |
|---|---|---|
| 見えるもの | 戦場全体 | そのごく一部 |
| 得意なこと | 連携、撤退、支援要請 | 重要地点の保持、精密な押し込み |
| 弱点 | 突然の突破への反応が遅い | 1つの戦闘への視野狭窄 |
| 失敗状態 | 崩壊する側面を無視する | 残り3つの側面を無視する |
| 理想のタイミング | 交戦前と交戦の合間 | 突破時、または時間制限のある目標中 |

### 直接操作に切り替えるべき時

- 防衛線が崩れそうで、あと1丁の火力が必要なとき。
- 避難目標に、勝手に離れない護衛が必要なとき。
- 高価値目標が露出しているのに、分隊が配置外にいるとき。

### 指揮ビューに留まるべき時

- 複数の脅威が同時に現れ、優先順位を決める必要があるとき。
- 車両がダメージを受けており、失う前に下げる必要があるとき。
- 支援アセットのクールダウンが明け、攻撃する価値のある対象があるとき。

プレイヤー体験から得られる有用な習慣は、頭の中でタイマーを設定することだ。短い交戦以上に直接操作を続けているなら、指揮ビューへ戻る。マップはあなたのために止まらないし、群れはあなたが良い戦いをしていることなど気にしない。

## ロサンゼルスを維持するための拠点建設の優先順位

Ebbtideの拠点建設は飾りではない。空間を時間に変換する方法だ。すべての建造物は、特定の問いに答えるべきである。これによって、他では維持できなかった何を維持できるようになるのか？

| 建設優先度 | なぜ枠を勝ち取るか | 省略した場合のリスク |
|---|---|---|
| 防御外周 | 開けた地面をキルゾーンに変える | 分隊が側面を突かれ、各個撃破される |
| 前線作戦基地 | 増援距離を短縮する | 損失のたびに長い帰路が発生する |
| 高所射撃位置 | 屋上が実効戦力を倍加させる | 街路が勝てない消耗戦になる |
| 車両集結エリア | 装甲を修理済み・準備万端に保つ | 戦車が遅れて到着するか、壊れて到着する |
| 退避線 | 撤退先を確保する | 1つの突破が全崩壊になる |

内部化する価値のある実践ルールが2つある。

1. **一列ではなく縦深に建てる。** 防御壁が1枚だけなら、それは単一障害点だ。層にすることで、対応に必要な数秒を買える。
2. **撤退できない場所には決して建てない。** 前線作戦基地は攻撃的な道具だ。出口のない位置なら、それは立派な名前の付いた罠でしかない。

コミュニティの報告によれば、民間人避難目標では自分の基地以外の何かを防衛させられるという。それにより計算が変わる。避難ルートは第二の前線であり、専用の援護部隊が必要だ。さもなければ、時間とコストのかかる失敗になる。

## 車両、砲撃、支援アセット

重装備はこのゲームで最も魅力的なものであり、最も無駄にしやすいものでもある。脇道で単独で死ぬ戦車は、戦車がいないよりも悪い。代価を払ったのに何も得られないからだ。

| アセット | 最適な用途 | 注意すべきこと |
|---|---|---|
| 主力戦車 | 密集した群れの塊を崩す | 包囲されて動けなくなること |
| ヘリコプター | 再配置、回収、迅速な対応 | それだけを見続けてしまうこと |
| 砲撃 | 既知の接近ルートへの先制攻撃 | 味方分隊がいる区域への射撃 |
| 歩兵分隊 | 装甲の援護と地面の保持 | 分散しすぎて集中射撃ができないこと |
| 屋上チーム | 比較的安全な場所からの継続射撃 | アクセス経路を失って孤立すること |

すべてに共通するパターンは同じだ。支援アセットは計画を増幅するものであり、計画の代わりにはならない。何を維持しようとしているのか分からなければ、戦車が教えてくれるわけではない。サバイバル・ストラテジーという広いジャンルがこうしたトレードオフをどう扱っているかを知るには、[Steamのサバイバル＆ストラテジーカタログ](https://store.steampowered.com/)を眺めるのが有用な比較練習になる。長く生き残るゲームは、支援ツールに明確なカウンターがあるものだと気づくだろう。

### クリーンなランと乱れたランを分ける5つの習慣

| ミス | なぜ痛いか | 修正 |
|---|---|---|
| 1回の攻勢に過剰投資する | 1つの悪い交戦で軍全体が消える | 最初には決して投入しない予備戦力を保つ |
| 屋上を無視する | 群れの条件で戦うことになる | 常に少なくとも1つの高所を保持する |
| 砲撃を溜め込む | 使わないダメージは無駄なダメージ | 接触時ではなく接近ルートに撃つ |
| 指揮ビューで戦う | 勝てた局地戦を落とす | 防衛線が崩れそうなときに降りる |
| 直接操作で戦う | 1本の通りに勝ちながら戦争に負ける | タイマーを設定して戻る |

## よくある質問（FAQ）

**Ebbtideに発売日はありますか？**
確定したローンチ日は発表されていない。プロジェクトはまだ開発中で、スタジオはプレビューで示された機能やビジュアルが変わる可能性があると示唆している。コメント欄で見た日付を前提に計画する前に、公式チャンネルを確認しよう。

**このEbbtideゲームプレイガイドは最終版にも当てはまりますか？**
一部は。軍隊を指揮することと、一人の生存者として戦うことの間の核心的な緊張は、デザインの土台であるように見える。そのため、配置、装甲の援護、縦深防御に関する戦術は引き継がれるはずだ。具体的な数値、ユニットバランス、建設コストはほぼ確実に当てはまらない。

**分隊を指揮するだけで、自分では戦わずに勝てますか？**
コミュニティ映像を見る限り、純粋な指揮プレイは可能だが難しい。特定の地点に「体」を置くことが求められる瞬間があるからだ。成功しているプレイの多くは、短く決定的な直接操作のバーストを行い、その後、指揮レイヤーへ戻る形のようだ。

**新規プレイヤーが最初に学ぶべきことは？**
切り替えを学ぼう。ユニットの相性やビルドオーダーを覚える前に、マップを見失わずに指揮ビューと直接操作を行き来する練習をしよう。その習慣1つは、どんなティアリストよりも価値がある。そして、このEbbtideゲームプレイガイドが最初に練習リストへ入れるものでもある。

**Ebbtideはストラテジーゲームですか、それともサバイバルゲームですか？**
本当に両方であり、それが魅力だ。サバイバル層は個々の戦闘に重みを与え、ストラテジー層はそれに結果を与える。片方のジャンルを楽しみ、もう片方を疎ましく思うプレイヤーは、中間地点を居心地が悪いと感じるだろう。それはコミットする前に知っておく価値がある。
