Ebbtideで築く壁はすべて崩れ得る――そしてゲームは、それがいつ、どこで起きたかを正確に記憶している。Ebbtideの建物破壊は、カメラが外れたらリセットされる飾りのパーティクル効果ではない。見ていようがいまいがシミュレーションを続ける戦場への、恒久的な変化だ。この一つの設計選択が、弾薬の使い方、前線作戦基地の置き場所、そして瓦礫を守って大隊を消耗させるより地区を放棄したほうが賢いのはいつか、という判断を根本から変える。

## Ebbtideの建物破壊が作戦マップで意味するもの

核心となる売り文句は、マップそのものが*戦場*だということだ。作戦マップ上で任意の通りにズームインすると、ロード画面なしでそのままライブ戦場になり、ズームアウトしても戦闘は動き続ける。何もサイコロの判定に抽象化されない。公式Steamページによれば、失った兵士、倒したゾンビ、破壊した建物はすべてマップに反映される。

つまりEbbtideの建物破壊は、戦闘の問題であると同時に兵站の問題でもある。崩れた壁は単なる外周の穴ではない。再び運び込まなければならない建材であり、失われた射撃位置であり、場合によっては輸送隊がもう通れない道路でもある。

| 戦場での出来事 | 作戦マップでの代償 |
|---|---|
| 壁の一部が崩落 | 代替資材をトラックかスリングで運び込む必要がある |
| 前線基地が制圧される | 再武装・再給油拠点がネットワークから消える |
| 輸送隊が待ち伏せされる | 建設資材と弾薬の配送が届かなくなる |
| 地区が「喪失」へ移行 | 集結地、遮蔽、視線が失われる |
| 兵士が群れに殺される | そのユニットは失われ、敵として戻ってくる可能性がある |

実践的な要点：すべての建造物は消耗品、すべての*位置*は貴重と考える。問うべきは「この建物を維持できるか」ではなく、「それを失うと補給距離の面でどれだけのコストがかかるか」だ。

## Ebbtideの建物破壊を支える火力

Steamページは率直だ。艦船の弾薬庫は有限であり、重火器は建物を倒す。この一文に、Ebbtideの建物破壊の経済が凝縮されている。平らにした建造物ごとに、オンデマンドで生産できない何かを支払う――ミサイルセル、ロケットポッド、空母甲板からの出撃だ。

確認されている火力は4つの系統に分かれる：

- **地上砲兵：** M777榴弾砲とHIMARSロケット
- **艦砲射撃：** 駆逐艦の主砲とトマホーク巡航ミサイル
- **空爆：** 空母のF/A-18、さらにF-15E、F-35B、A-10による攻撃
- **持続的航空支援：** AC-130JガンシップとMQ-9ドローンの周回

| システム | 配備元 | 構造物への役割 | 主なコスト |
|---|---|---|---|
| M777榴弾砲 | 地上砲兵隊 | 建物密集地帯への持続的な間接射撃 | 輸送隊による弾薬補給 |
| HIMARSロケット | 地上発射機 | 今すぐ拠点を排除したいときの高速で強力な対応 | 限られたポッド |
| 駆逐艦の主砲とトマホーク | 空母打撃群の護衛艦 | 都市部まで届く洋上火力支援 | 有限の艦船弾薬庫 |
| F/A-18、F-15E、F-35B、A-10 | 空母および陸上航空戦力 | 精密または持続的な攻撃任務 | 機体の可用性と燃料 |
| AC-130JとMQ-9 | 滞空航空機 | 地区上空での監視と火力支援 | 周回時間と燃料 |

設計上の緊張はプレイすれば明らかだ。外周から群れを一掃する道具は、残しておきたかった遮蔽物を消し去る道具でもある。攻撃を要請する前に、自分が脅威を取り除こうとしているのか、未来の射撃位置を取り除こうとしているのかを決めよう。

## Ebbtideの建物破壊に耐える基地を建てる

Ebbtideの基地建設は即席ではなく意図的だ。どこに陣取るかを選び、HESCOとコンクリートの壁を築き、壁線を守るための門と足場を追加し、銃座、CIWS、迫撃砲陣地、弾薬庫、燃料補給点、照明を配置する。それらすべてを動かし続けるのは補給だ――兵士、車両、航空機は弾薬と燃料を消費し、自分が保持する基地でしか再武装・再給油できない。

壁ごとに、フックリフトトラックやヘリコプターのスリングで建材を運び込む必要がある。つまり防御計画と兵站計画は同じ文書になる。

| 構造物 | 基地での役割 | 建設優先度 |
|---|---|---|
| HESCOとコンクリートの壁 | 群れに対する主要な障壁 | 最優先――他のすべてはその背後にある |
| 門 | 味方の移動を管理 | 高――ただし門はどれも弱点 |
| 足場 | 防御側が壁線から戦えるようにする | 脅威にさらされる面では高 |
| 銃座 | 近接外周防御 | 高 |
| CIWS | 高速の脅威に対する点防御 | 中高 |
| 迫撃砲陣地 | 壁の外への間接射撃 | 中 |
| 弾薬庫 | 守備隊の再武装拠点 | 中高 |
| 燃料補給点 | 車両と航空機への給油 | 中 |
| 照明 | 夜間圧力下での視界 | 中 |

### Ebbtideの建物破壊を加速させるよくあるミス

- **一度にすべてを壁で囲う。** 資材はトラックとスリングで届くため、広大な外周は自ら補給を枯渇させる。
- **道路網を無視する。** 群れは輸送隊を狙い、道路を断つ。補給できない基地はすでに失われている。
- **戦闘中に建設する。** 群れがすでに登っている場所ではなく、備蓄できる場所に陣取る。
- **照明を省く。** 暗い壁線は守れない壁線だ。
- **基地防御に重火器を過剰投入する。** 艦船の弾薬庫は有限だ。景観ではなく脅威に使う。

## 群れがあなたの建造物をどう壊すか

Ebbtideのゾンビは、銃口に向かって歩いてくるだけの波ではない。彼らは積み重なって壁や屋上を登り、低空でホバリングするヘリコプターにしがみつく。群れに殺された兵士はゾンビとして再び起き上がる――つまり防衛の失敗は、文字通りあなたへの攻撃を強化し得る。

| 群れの行動 | なぜ基地を脅かすか | 実践的な対抗策 |
|---|---|---|
| 積み重なって壁や屋上を登る | 外周を垂直方向に迂回する | 射界を重複させる。足場上の防御者 |
| 低空ホバリングするヘリにしがみつく | 航空兵站を直接脅かす | ホバリング時間を短くし、輸送を護衛する |
| 兵士を殺し、その兵士が起き上がる | 自分の外周が敵を補強する | 犠牲を素早く封じ込める。陣地内に遺体を残さない |
| 輸送隊を狙い、道路を断つ | 建設と再武装を飢えさせる | 経路を護衛し、時間帯を変える |

屋上への登攀は、基地設計を最も大きく変える要素だ。地上攻撃には完璧な壁も、隣の建物が残っていれば階段になる――そしてEbbtideでは、たいてい残っている。

## 地区への圧力：いつ拠点を放棄するか

ロサンゼルスは15の地区に分かれ、「保持」から「危機」を経て「喪失」へと移行する。作戦マップを一時停止したり、最大4倍速で進めたりできるが、全員を救うことはできない――だから本当のスキルは、誰を先に引き揚げるかを見極めることだ。

州兵、LAPD、ロサンゼルス郡保安官局の部隊に保持・遅滞・撤退を命じ、キャンプ・ペンドルトンから海兵隊を呼び寄せられる。トラックとヘリコプターの輸送隊は物資、部隊、難民を運ぶ。戦線の背後で孤立した部隊や生存者は、群れが到達する前に抽出できる。味方の視線内にいる群れだけがマップに表示されるため、偵察は任意ではない。

| 地区の状態 | 意味 | 妥当な対応 |
|---|---|---|
| 保持 | 制御下にあり利用可能 | 要塞化し、備蓄し、兵站拠点として使う |
| 危機 | 争奪中、または崩れつつある | 短時間だけ増援するか、遅滞させて退避を準備する |
| 喪失 | 制圧済み | 部隊を送り込むのをやめる。生存者を抽出し、可能な限り回収する |

ロサンゼルスの決着がつくと、ロサンゼルス港に持ち込んだ人々、部隊、装備、物資が、世界キャンペーンでアーク艦上から始める初期戦力になる。どの地域を支援するかを選び、空母打撃群の砲と航空機を射程内に入れ、友好港で補給し、同盟軍艦で艦隊を拡張し、Nexusの隠された指揮ノードを追跡する。

## FAQ

**Ebbtideで破壊された建物を再建できますか？**
Steamの掲載情報では、建物破壊が作戦マップ上で持続することは確認されているが、ProjectAliveは修理・再建システムの詳細を明らかにしていない。確認されているのは、前線作戦基地を自分で建設・拡張できるということなので、瓦礫を無料で復元するのではなく、運び込んだ資材で陣地を再確立するつもりで計画しよう。

**Ebbtideの建物破壊を最も引き起こすものは何ですか？**
重火器。榴弾砲、HIMARS、駆逐艦の主砲、トマホーク巡航ミサイル、航空機攻撃はいずれも建造物を倒すことが確認されている。艦船の弾薬庫は有限なので、破壊のたびに将来の火力支援とのトレードオフになる。

**なぜEbbtideの建物破壊が基地設計で重要なのでしょうか？**
壁はフックリフトトラックやヘリコプターのスリングで届く資材を消費し、群れはその輸送隊を狙うからだ。補給を維持するには大きすぎる基地は、再建が追いつくより速く区画を失う――コンパクトで照明が行き届き、射界に優れた陣地のほうが長く生き残る。
